# Ojak 브랜드·재미 요소 스펙 (외부 PR 배포용)

## 결정 사항 (2026-10-03 사용자)
- 풍자 수위: **가볍지만 강도 있게.** 웃기되 할 말은 한다. 근거는 공급자 공식 문구만.
- 도트 범위: **전면.** 앱 화면 전체 테마까지. 단, 현재 오작교 까치 로고는 **그대로 유지**한다.
- 출시 일정: 10월 29일(OpenAI Pro 200 기존 가입자 혜택 종료일)에 맞추지 않는다. 품질 우선.
- 마스코트 이름: **깍이.** 이중 의미가 핵심이다. ① 까치 울음 "깍깍"의 애칭, ② "토큰 맨날 깍네"(요금제가 한도를 깎는다)의 풍자. 공식 소개 문구에서는 ①을 앞에 두고, 캠페인 카피에서 ②를 쓴다. 예: "요금제는 맨날 깍고, 깍이는 안 흘리고."
- 원화 제작: AI 생성 시안 여러 개로 의미·컨셉을 먼저 정한 뒤 리터칭. 랜딩은 사용자가 별도 URL로 진행.

## 원칙 (재미보다 먼저)
1. **숫자는 농담하지 않는다.** 한도 %, 리셋 시각, 배정 사유는 도트 테마에서도 정확하고 읽기 쉬워야 한다. 숫자·이메일·경로는 시스템 글꼴(tabular-nums) 유지.
2. **풍자는 정책을 향한다.** 회사·사람을 조롱하지 않는다. 경쟁사 로고·트레이드 드레스를 흉내 내지 않는다. 회사명은 사실을 서술할 때만.
3. **사실은 원문 그대로.** 풍자 문구 옆에 공식 출처 링크와 확인 날짜를 붙인다. 제3자 추정 수치는 쓰지 않는다.
4. **"우회"를 팔지 않는다.** `2026-09-27-release-distribution.md`의 홍보 문구 원칙을 그대로 따른다. 메시지는 "내가 낸 한도를 남김없이"이지 "한도를 피해서"가 아니다.
5. **진지 모드.** 마스코트 대사·효과음·게임식 용어를 한 번에 끄고 일반 용어로 되돌리는 스위치. 회사 화면 공유·발표용.
6. **개인정보.** 공유 카드·업적·스크린샷에 이메일·프롬프트·프로젝트 경로를 넣지 않는다. 공유는 미리보기 확인 후에만.

## 세계관
- 이름의 뿌리: 오작교(烏鵲橋) — 까마귀와 까치가 놓는 다리. **개발자와 한도를 잇는 다리.**
- 풍자의 뿌리: 민화 **까치호랑이**. 원래 어수룩한 호랑이(권력)와 영리한 까치(서민)로 권세를 비꼬는 그림이다. 여기서 호랑이 = 요금제 정책, 까치 = Ojak과 사용자.
- 톤: 해학. 화내지 않고 비튼다. 마지막은 늘 사용자에게 득이 되는 행동(남은 한도 쓰기, 덜 낭비하기)으로 끝난다.

## 디자인 시스템: 도트 민화

### 유지
- 앱 아이콘·로고: 현재 오작교 까치 아이콘 그대로(`apps/desktop/src/assets/ojak-icon.png`, `src-tauri/icons/`). 도트 마스코트는 로고를 **대체하지 않고** 로고에서 파생한다(같은 실루엣·흑백 깃·흰 배).

### 새로 정할 것
- **마스코트 "깍이"(가칭)**: 16×16 / 32×32 도트 까치. 상태 6종 스프라이트(2~4프레임).
  | 상태 | 조건 (기존 데이터) | 모습 |
  |---|---|---|
  | 쉼 | 최근 15분 사용 없음 | 다리 위에서 졸음 |
  | 나름 | 브릿지·관리 세션 활성 | 부리에 편지 물고 날기 |
  | 헐떡 | 쓰는 계정 잔여 ≤ 30% (`remainingTone` warn) | 땀방울 |
  | 기절 | 소진·여유분 이하 (`bad`) | 눈 X, 다리에 걸침 |
  | 부활 | 리셋 직후(소진→관측 회복) | "깍깍!" 말풍선 |
  | 급함 | `quotaSummaries[].expiring` 존재 | 시계 들고 손짓 |
- **팔레트**: 민화 오방색을 낮은 채도로(청·적·황·백·흑) + 기존 상태색(`--good`/`--warning`/`--danger`/`--accent`) 유지. 상태색 의미는 바꾸지 않는다.
- **글꼴**: 제목·마스코트 말풍선·빈 화면·업적 = Galmuri(SIL OFL 1.1, https://github.com/quiple/galmuri). 숫자·표·이메일·경로 = 시스템 글꼴. 도트 글꼴은 정수 배율(1×/2×)로만 렌더링해 번짐을 막는다.
- **UI 테두리**: 1px 계단식 도트 테두리, 그림자 대신 2px 오프셋. 다크/라이트 모두.
- **메뉴바 아이콘**: macOS 템플릿 이미지 규칙(단색) 때문에 상태 애니메이션은 넣지 않는다. 팝오버 안에서만 마스코트를 움직인다.

### 화면별 적용
| 화면 | 적용 |
|---|---|
| 팝오버 | 상단 마스코트 + 한 줄 대사. 카드 테두리 도트화. 잔여 막대는 HP 바 모양(블록 단위)이나 % 숫자는 그대로 |
| 사용 현황 | 제목 도트 글꼴, 계정 카드 도트 테두리, 잔여 막대 HP 바. "곧 리셋" 안내 앞에 급함 까치 아이콘 |
| 빈 화면·오류 | 상태별 까치 그림 + 다음 행동 문구 (예: 연결 끊김 = 다리 끊긴 그림 + [다시 연결]) |
| 설정·배정 설정 | 폼은 기존 컨트롤 유지(접근성). 섹션 제목만 도트 |
| 첫 실행 안내 | 다리 놓기 연출: 단계마다 까치가 한 마리씩 날아와 다리 완성 |

## 앱 안 재미 기능

### 1. 게임식 용어 (진지 모드에서 일반 용어로)
| 일반 | 게임식 |
|---|---|
| 남은 한도 | HP |
| 소진 | 기절 |
| 리셋 | 부활 |
| 리셋 전 남은 한도 | 사라질 경험치 |
| 자동 전환 | 교대 |

### 2. 질소과자 지수 (데이터 기반 풍자, 출시 후)
- 정의: **본인 계정에서** 같은 모델로 보낸 요청 1회당 소비된 한도 %의 중앙값을 주 단위로 추적. "지난 4주 대비 질소 +18%".
- 근거 데이터: 브릿지 요청 수(이미 기록) + 버킷 사용률 관측 변화(관측 이력 저장 필요). 요청 길이·모델 차이로 생기는 잡음이 커서 **표본 기준 미달이면 표시하지 않는다**("아직 봉지를 덜 뜯었어요").
- 표현: "질소 ↑/↓" + 문장. 공급자 비교 랭킹은 만들지 않는다(우리 데이터로 타사를 단정하지 않음).

### 3. 주간 영수증 카드 (PR 확산용)
- 도트 영수증 PNG: 이번 주 리셋 때 남긴 한도 %, 교대 횟수, 낭비 0% 여부, 가장 많이 쓴 모델(이름만), 까치 한 줄 평.
- 제외: 이메일, 계정 수 외 식별자, 프로젝트명, 프롬프트. 생성은 로컬, 업로드는 하지 않는다. 사용자가 저장·복사.

### 4. 업적 (로컬 전용, 효율 보상)
- 오작교 개통(첫 관리 요청), 낭비 0주(리셋 시 쓸 수 있던 한도 < 5%), 칼교대(소진 직전 자동 전환), 부엉이(새벽 3시 요청 — 건강 문구 동반), 칠석(음력 7/7 사용).
- 사용량을 늘리게 만드는 업적은 만들지 않는다.

### 5. 이스터에그
- 칠석 당일 오작교 테마, 코나미 커맨드 → 까치호랑이 도트 장면(호랑이가 "효율화" 저울을 든 그림). 진지 모드에서는 비활성.
