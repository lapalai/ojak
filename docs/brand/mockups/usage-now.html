사용 현황 시안 — 호랑이 저울은 어디에, 어떻게

같은 가짜 데이터로 그렸습니다. Claude 계정 3개(한 계정은 주간 한도 1일 뒤 리셋인데 60% 남음, 한 계정은 너무 빨리 쓰는 중), Codex 1개.

이 화면에서 사용자가 답을 얻어야 하는 질문은 하나입니다. "리셋 전에 낭비될 계정, 또는 곧 막힐 계정이 있나?"
지금 막대는 남은 양만 보여 줘서, 1일 뒤 리셋인데 60% 남은 계정 A(낭비 위험)와 4일 뒤 리셋인데 60% 남은 계정 B(속도 적당)가 똑같이 보입니다.

지금 화면

문제 — A와 B가 둘 다 "60% 남음, 초록"이라 구분이 안 됩니다. A는 내일 리셋이라 지금 써야 하는 계정인데 화면이 알려 주지 않습니다.
곧 리셋 안내가 있긴 하지만 설정 기준(48시간·30%)에 걸릴 때만 한 줄로 나옵니다.
A · 추천

막대에 "고르게 썼다면 지금 여기" 눈금 하나

눈금 = 리셋까지 고르게 쓴다면 지금 남아 있어야 할 양막대가 눈금보다 길면 → 남는 쪽(먼저 쓰기)막대가 눈금보다 짧으면 → 빨리 쓰는 쪽
장점 — 새 위젯 없이 기존 막대에 눈금만 더합니다. 데이터 요금제·가계부 앱에서 익숙한 방식이라 따로 배울 필요가 없습니다. 색약 사용자도 길이로 읽습니다.
호랑이 저울은? — 정보 표시가 아니라 아래 "요약 띠"처럼 알릴 일이 있을 때만 등장합니다. 숫자는 막대가, 기억은 저울이 맡습니다.
B

계정마다 호랑이 저울

장점 — 한국적이고 브랜드가 강하게 보입니다. 기울기로 "어느 쪽이 무거운지" 직관적입니다.
위험 — "쌀 쪽이 무겁다"를 "쌀이 많다 = 괜찮다"로 읽기 쉬워, 정작 알리고 싶은 "먼저 써야 한다"가 반대로 전달될 수 있습니다. 계정마다 그림이 하나씩 붙어 화면이 무거워집니다.
A와 함께

호랑이 저울 + 깍이 요약 띠 (알릴 일이 있을 때만)

언제 — 리셋 전에 쓸 게 남은 계정이 있을 때, 또는 쓰는 계정이 곧 막힐 때만. 평소엔 숨깁니다.
누르면 — 해당 계정 카드로 이동하고, 그 카드의 막대 눈금이 잠깐 강조됩니다.
롤백 완료

메뉴바 아이콘 클릭 팝오버 — 기존과 동일

팝오버는 원래대로 되돌렸습니다. 깍이 한 줄과 계정별 저울을 빼고, 작은 막대와 % 숫자만 남겼습니다. 잔여량 색 기준(31% 이상 초록 · 30% 이하 주황 · 여유분 이하 빨강)은 앞서 맞춘 그대로입니다.
