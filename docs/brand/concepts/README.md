## 검토 메모
- 캐릭터 일관성: 다섯 장 모두 같은 깍이(검은 머리, 흰 배, 청록 꼬리)로 나왔다. A 시트를 기준 원형으로 쓴다.
- 현재 로고와의 관계: 로고는 그대로 두고, 깍이는 로고 실루엣의 귀여운 확장판으로 쓴다.
- E의 "넘어간다" 연출은 "요금소를 피해 간다"로 읽힐 수 있다. 홍보 원칙("우회"를 팔지 않는다)과 충돌할 수 있어, 쓸 경우 "일반 차로로 정상 통과"로 다시 그린다.
- D의 `$200`은 공식 가격 사실이지만, 단독 이미지로 퍼지면 출처 없이 읽힌다. 게시할 때는 출처 캡션을 반드시 함께 붙인다.
- 생성 이미지는 2026-10-03 ChatGPT gpt-image 산출물이다. OpenAI 이용약관(2026-01-01)상 이용자와 OpenAI 사이에서는 산출물 권리가 이용자에게 있어 저장소와 앱에 싣는 것과 맞다. 기존 저작물 유사성은 약관이 보장하지 않는다. 민화 패러디와 병풍의 빨간 원은 아래 리터칭 메모를 따른다. 사람 그림이라고 쓰지 않는다. 고지: [THIRD_PARTY_NOTICES.md](../../../THIRD_PARTY_NOTICES.md).
- 글로벌: 쌀알은 해외에서도 "새가 나르는 귀한 알갱이(grain)"로 읽힌다. 금색으로 그리면 크립토 코인처럼 보이므로 진주빛 흰색 + 반짝임으로 고정한다. 국문은 쌀알·한 톨, 영문은 grain.
- 요청 표현 통일: B 오작교의 편지 = 요청은 쌀알 = 토큰으로 바꾼다. 다리를 건너는 것은 쌀알 행렬이다. 편지는 쓰지 않는다.
- G 7번 컷 뒤 검은 얼룩(생성 오류)과 컷마다 다른 배경 얼룩은 리터칭 때 단색 배경으로 정리한다.
- H의 저울은 풍자(호랑이가 속이는 저울)와 기능(깍이가 정직하게 읽는 저울)을 잇는 핵심 소품이다. 앱 저울은 곧 리셋 판정과 같은 근거(남은 % vs 리셋까지 시간)로 기울기만 그린다.
- H 리터칭: 아랫단 배경색(크림·하늘·주홍·노랑)은 앱 상태색과 의미가 다르므로 빼고 테두리만 상태색으로. 윗단의 일본풍 노렌은 한국 쌀가게 소품(멍석·가마니·됫박)으로 교체.
- **FINAL-H 병풍의 빨간 원(해)**: 흰 바탕 + 빨간 원이 일장기로 읽힐 수 있다. 국내 PR에서 가장 먼저 지적될 수 있으므로 리터칭 때 일월오봉도식 해·달 한 쌍이나 소나무로 바꾼다.
