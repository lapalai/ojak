    세션

    omp, Claude Code, Codex에서 지금 열려 있는 세션입니다. 한 세션은 한 계정에 고정됩니다.
    프로젝트도구모델계정요청마지막 사용

    배정 정책

    아래 규칙은 omp(AAM 모델), Claude Code, Codex의 새 세션에 똑같이 적용됩니다. 이미 시작된 응답은 계정을 바꾸지 않습니다.

    계정을 고르는 기준

    배정 방식
    리셋이 가까운 계정의 남은 한도를 먼저 씁니다. 5시간 한도를 85% 넘게 쓴 계정은 뒤로 미룹니다.
    안전 여유량
    이만큼 남으면 그 모델에는 새 세션을 보내지 않습니다. 모델 전용 한도(Fable 등)에도 적용합니다.
    %
    세션 고정
    같은 세션은 마지막 사용 후 60분까지 같은 계정을 씁니다. 프롬프트 캐시를 지키기 위해서입니다.
    한도 소진 시
    응답 시작 전이면 다음 계정으로 바로 다시 보냅니다. 모든 계정이 막히면 가장 이른 리셋 시각을 알려 주고 멈춥니다.
    고정 동작

    계정 순서와 배정 포함

    끄면 omp, Claude Code, Codex 모두 이 계정을 쓰지 않습니다
